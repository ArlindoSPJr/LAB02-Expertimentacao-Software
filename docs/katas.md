# Katas

### 1. Validação de Palíndromo
Recebe uma string como entrada e deve retornar se ela é um palíndromo, ou seja, se a leitura da esquerda para a direita é igual à leitura da direita para a esquerda.
Exemplo: entrada `"arara"` → `true`; entrada `"banana"` → `false`.

### 2. Contagem de Ocorrências de um Caractere
Recebe dois parâmetros: um caractere e uma string. Deve retornar quantas vezes esse caractere aparece dentro da string.
Exemplo: caractere `"a"`, string `"banana"` → `3`.

### 3. Contagem de Sequências Crescentes
Recebe uma sequência de números como parâmetro. Deve retornar quantas sequências consecutivas de números crescentes, com no mínimo 3 números, existem dentro dela.
Exemplo: `[1, 2, 3, 1, 5, 6, 7, 8, 2]` → `2` (as sequências `[1, 2, 3]` e `[5, 6, 7, 8]`).
